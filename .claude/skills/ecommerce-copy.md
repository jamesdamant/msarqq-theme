# E-commerce product copy

## Voice

Write like a sharp human selling something they'd buy themselves. Concretely:

- Plain verbs. "is / has / works with" over "serves as / boasts / features".
- Specifics over superlatives. "Flies 8 minutes per charge" beats "long-lasting fun".
- Varied sentence length. If every sentence is the same length, rewrite.
- Have an opinion. "The kick is the prop guards — most drones this size don't have them."
- Trust the parent buying for a kid: answer their real questions, don't hype.

## AI-slop tells to strip on every pass

- Vocabulary: elevate, seamless, unleash, game-changer, vibrant, testament, pivotal, delve, "when it comes to", "in a world where".
- Negative parallelism: "It's not just X, it's Y."
- Rule-of-three padding: "fun, fast, and fierce" → cut to what's true.
- "-ing" depth-faking: "highlighting... ensuring... reflecting..." trailing clauses.
- Bold-header bullet spam, emoji bullets, title case headings, em-dash chains, curly quotes.
- Hedging stacks ("could potentially") and vague attribution ("experts say").
- Reassurance kickers ("And that's okay.") and mic-drop fragments ("It just works.").

## Product page structure (per product)

1. **Title** — ≤60 chars, benefit or plain-descriptive, front-load the search word. "Flying Soccer Drone — Hover Ball You Kick, Not Fly" not "Revolutionary Aerodynamic Sports Device".
2. **Subhead / first line** — one sentence on who it's for and the core fun. Name the buyer, not just the product: "for kids 6+ who wreck everything".
3. **Bullets (3–5)** — each: feature → benefit → concrete proof or number. One idea per bullet, no bolded headers.
4. **Description** — answer buyer objections in order of how much they block purchase. For toys: age range, what's in the box, battery + charge time vs play time, durability/safety (prop guards, materials), where it can be used (indoors? walls?), how hard to learn.
5. **Meta title** ≤60 chars, **meta description** 140–160 chars, natural phrasing — never a keyword list.

## Process

1. Read the product details. If a fact isn't given, don't invent one — flag it.
2. Draft.
3. Anti-AI pass: "What makes this obviously AI-generated?" Fix the tells.
4. Read aloud test: if you wouldn't say a sentence to a customer standing in front of you, rewrite it.
5. Deliver to the requested file or format. Don't paste full copy into a chat response when a file was asked for — write the file, summarize in one or two lines.
